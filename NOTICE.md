# Acknowledgements

This project was inspired by Patrick Belanger's
[SeriousWebcamSettings](https://github.com/PatBQc/SeriousWebcamSettings),
an MIT-licensed Windows application. The original project's product ideas—
showing only supported webcam controls, saving profiles, and periodically
reapplying settings—guided this independent C++ implementation.

No AForge, WPF, C#, artwork, or binary code from the reference project is
included here.

Webcamoid was consulted only as prior art when identifying useful capability
categories. This repository contains no Webcamoid source code, algorithms, assets,
or plugin code. Its dynamic control model and platform backends were implemented
independently from the Windows SDK, Linux V4L2 headers, Qt documentation, and
PipeWire node metadata.
